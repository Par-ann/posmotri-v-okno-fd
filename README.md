# Посмотри в окно

Проект выполнен в рамках обучения на курсе «Веб-разработчик» Яндекс Практикума.

## Описание проекта

«Посмотри в окно» — это веб-страница с видеоплеером и списком карточек, позволяющая выбирать различные видеоролики и фильтровать их по параметрам.

В проекте реализованы:

* адаптация макета в соответствии с дизайн-макетом;
* работа с Flexbox;
* стилизация форм;
* кастомные чекбоксы;
* состояния интерактивных элементов (hover, focus, active);
* оформление списка карточек и области прокрутки;
* использование БЭМ-методологии.
